# Segurança — Visão Geral

Ver `security/policies/`, `security/threat-model/`,
`security/incident-response/`, `security/backup-policy/` e
`security/disaster-recovery/` para o detalhe de cada área.

Pilares: Cloudflare WAF/DDoS, rate limiting, validação de input,
protecção SSRF/command injection/path traversal, sessões seguras, MFA,
RBAC, least privilege, gestão de secrets, encriptação, verificação de
webhooks, audit logs, rotação de credenciais, backups testados,
dependency scanning, isolamento de containers, limites de recursos,
isolamento de rede, redaction de logs, segurança de CI/CD.
