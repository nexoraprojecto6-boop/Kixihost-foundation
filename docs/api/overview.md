# API — Visão Geral

A API (`apps/api`, NestJS) expõe os endpoints consumidos por `apps/web`
e `apps/admin`. Módulos previstos: auth, github, projects, deployments,
domains, billing, payments, admin (ver `apps/api/src/modules/README.md`).

Documentação OpenAPI/Swagger será gerada a partir da Fase 2.
