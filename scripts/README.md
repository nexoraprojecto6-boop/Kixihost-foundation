# scripts/

Scripts administrativos e de manutenção, para uso a partir do terminal
(ver regra 3): instalação, actualização, diagnóstico — nunca para
manter produção a funcionar.

- `setup-check.sh` — verificação estática da fundação, não inicia serviços.
- `generate-secrets-template.sh` — gera secrets aleatórios apenas para
  desenvolvimento local.
